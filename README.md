# 🛒 Amazon Clone (HTML & CSS)

A simple and responsive **Amazon landing page clone** built using **only HTML and CSS**. This project is purely for educational purposes to improve frontend layout and styling skills.

---

## 🚀 Features

- Amazon-style navigation bar with logo, search, and location
- Product grid layout with cards and hover effects
- Multi-column footer with links
- Fully responsive using Flexbox and media queries
- No JavaScript — pure HTML and CSS

---

## 🛠️ Technologies Used

- ✅ HTML5
- ✅ CSS3 (Flexbox, Grid, Media Queries)
